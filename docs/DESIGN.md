## 수달 그림 규칙
- **수달은 프로젝트 그림(public/assets/otter)만 쓴다.** 새로 그리거나 다른 그림과 겹쳐 쓰지 않는다.
- 상태마다 그림 한 장(`OtterSprite`의 `src`만 바꾼다)에 CSS 움직임을 준다.
  - work: 0.5초마다 살짝 기울며 두드리기 (rotate -3deg, translateY -3%)
  - sleepy: 좌우로 천천히 흔들기 (±2.5deg, 1.8초)
  - sleep / idle: 숨쉬기 (scale 1.02 × 0.965, 2.4초)
  - surprise: 한 번 튀어 오르기 (0.5초)
- reduced motion이면 움직임을 모두 멈춘다.

## DeskDemo (히어로, 방문자가 직접 해 보는 데모)
가짜 바탕화면 위에 인강 창, 집 진행도 칩, 타이머 말풍선, 수달.

- 실제 앱의 5분·10분을 **5초·10초**로 줄인다. 실제 1초 = 공부 1분.
- `useIdleState`: 입력 이벤트(pointermove, pointerdown, keydown, wheel, touchstart, scroll)
  - 무입력 5초 → sleepy (시간 계속 쌓임)
  - 무입력 10초 → sleep (시간 멈춤)
  - sleepy·sleep 중 입력 → surprise 0.6초 → work
- 집 30분(=30초)이 차면 1.6초간 완성 이미지 → 다음 집. 6채마다 마을 카운트 초기화.
- 아래 안내 문구가 상태마다 바뀐다. sleepy·sleep일 때 "(실제 앱은 5분 · 10분)"을 붙인다.

## ScenePlayer (자동 재생 장면 + 단계 사진 카드)
모아냥의 자동 재생 데모처럼, **위에는 장면이 영상처럼 재생되고 아래에는 단계별 사진 카드가 이어 붙어 있다.**

- 구성: `screen`(장면) 안 하단에 자막 바(`n / N`, 문구, 재생·일시정지 버튼), 그 아래 카드 목록
- 챕터마다 `dur`(ms), `cap`(자막), `frame(p)`(0~1 진행도로 장면을 그림)
- 재생 중인 챕터의 카드에 `aria-current="step"` + 테두리 강조 + 아래 진행 막대가 차오름. 지난 카드는 막대 100%
- 카드를 누르면 그 챕터로 이동해 재생. 마지막 다음은 처음으로 반복
- 화면에 30% 이상 보일 때만 재생 (IntersectionObserver). reduced motion이면 자동 재생하지 않고, 카드를 누를 때 해당 장면을 멈춘 상태로 보여준다
- 자막은 `aria-live="polite"`, 장면 그림은 `aria-hidden`

### RestScene (수달 상태, 5챕터)
| # | 카드 | 장면 | 타이머 | 입력 표시 |
|---|---|---|---|---|
| 1 | 대기 | idle | 공부 전 00:00:00 | 공부 시작을 누르면 나타나요 |
| 2 | 작업 | work | 00:00 → 20:00 쌓임 | 입력 중 (키 깜빡임) |
| 3 | 졸림 | sleepy | 25:00 → 30:00 쌓임 | 입력 없음 05:00 → 09:59 |
| 4 | 잠듦 | sleep | 30:00 멈춤 (회색 점) | 입력 없음 10:00 → 14:00 |
| 5 | 깜짝 놀람 | surprise 40% → work | 30:00 → 다시 쌓임 | 커서가 움직이고 "입력 감지!" |

### HouseScene (집 짓기, 6챕터)
| # | 카드 | 장면 | 진행도 |
|---|---|---|---|
| 1 | 터 다지기 | house/stage1 + 옆에서 일하는 수달(work) | 0 → 20% |
| 2 | 뼈대 | stage2 (바뀔 때 pop) | 20 → 45% |
| 3 | 벽 | stage3 | 45 → 70% |
| 4 | 지붕 | stage4 | 70 → 100% |
| 5 | 완성 | stage5 + "1번째 집 완성!" 말풍선 | 100% |
| 6 | 마을 | screens/village 위 집터 6곳에 stage5가 하나씩 등장, "완성 n / 6", 끝에 "마을 완성! 다음 마을로 이어져요" |

- HUD: "1번째 집 짓는 중", 진행 막대, %, `mm:ss / 30:00` (진행도 × 18초)
- 마을 장면은 village 이미지에서 창 테두리를 잘라낸 900×470 영역을 쓴다 (이미지 폭 111.12%, left -10.56%, top -8.51%)
- 집터 위치(영역 기준 %, 집 아래쪽 기준): (20.6, 55.3) (41.9, 55.3) (63.3, 55.3) (20.3, 79.1) (41.4, 79.1) (63.0, 79.1), 집 폭 14.4%
- 원본 이미지의 "완성 0/6" 배지는 내 배지(min-width 15%)로 덮는다

### 반응형
- 장면 비율: 데스크톱 2:1, 900px 이하 16:10, 520px 이하 4:5 (자막이 2~3줄이 되어도 장면을 가리지 않게)
- 900px 이하: 카드 목록은 가로 스크롤 (scroll-snap)

## 폼
- 입력창 테두리 2px, 포커스 시 accent. 잘못된 값은 빨간 테두리 + 아래 메시지.
- 동의 체크 필수. "자세히 보기"를 펼치면 수집 항목·목적·보유 기간·거부 권리 표.
- 버튼 문구: 히어로 "출시 알림 받기", 하단 "출시 알림 신청하기". 보내는 중에는 "신청하는 중…"으로 바꾸고 비활성.
- 숨은 칸(website)에 값이 있으면 봇으로 보고 조용히 무시.

## 반응형
- 900px 이하: 히어로·단계·하단 영역 1열, 장면 아래 카드는 가로 스크롤
- 520px 이하: 장면 비율 4:5, 로드맵 1열
- 좌우 여백 최소 20px, 가로 스크롤 없음
