01

공부 시작을 누르면
수달이 바탕화면에 나와요

인강을 틀어 두든 문서를 쓰든, 어떤 창을 쓰고 있어도 화면 한쪽에서 수달이 같이 일해요. 마우스를 올리면 공부 시간과 빠른 버튼이 보여요.

투명 영역은 클릭이 통과돼요드래그로 자리 옮기기
▶ 공부 시작휴식종료
02

30분 공부하면 집 한 채,
여섯 채면 마을 하나

공부 시간이 쌓이는 만큼 집이 다섯 단계로 지어져요. 다 짓고 남은 시간은 다음 집으로 이어지고, 여섯 채가 모이면 마을이 완성돼요. 집 한 채에 필요한 시간은 5분부터 240분까지 바꿀 수 있어요.

03

쌓인 시간은
달력으로 돌아봐요

공부를 끝내면 이번에 공부한 시간, 쉰 시간, 완성한 집 수를 정리해서 보여줘요. 날짜별, 월별 공부 시간은 달력에 남고, 완성한 마을은 언제든 다시 볼 수 있어요.

지난 마을 다시 보기자동 저장 · 비정상 종료 복구

수달은 공부 내용을 보지 않아요

  • 키보드와 마우스를 쓰고 있는지만 확인해요. 무엇을 입력했는지는 보지 않아요.
  • 영상을 보거나 종이책을 읽는 동안에는 입력이 없어서 휴식으로 바뀔 수 있어요. 졸림과 휴식까지 걸리는 시간은 설정에서 늘릴 수 있어요.
  • 공부 기록은 내 컴퓨터에 저장돼요.

앞으로 지을 것들

마을은 계속 넓어져요

첫 버전은 집 짓기와 공부 기록부터 시작해요. 다음 기능의 순서는 신청해 주신 분들의 의견을 듣고 정해요.

V2

마을 둘러보기

  • 마을 확대·축소, 화면 이동
  • 집마다 공부 기록 연결
  • 주간·월간 리포트
V3

기록 남기고 공유

  • 마을과 공부 시간 인증 사진
  • 스토리·피드 비율로 저장
  • 과목과 메모 남기기
V4

꾸미기와 상점

  • 공부 시간으로 모으는 재화
  • 집과 수달 꾸미기 아이템
V5

함께 공부

  • 친구 수달과 같이 공부
  • 친구 마을 놀러 가기
  • 공부 시간을 모아 공동 건물 짓기
